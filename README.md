# GeTfi WiFi Vendo System

GeTfi WiFi Vendo System (pisowifi) para sa Orange Pi One.
Sa SD card image na ito, kasama na ang admin panel, portal, coin slot, voucher, at license system.

## Kailangan
- Orange Pi One
- SD card, 16 GB pataas, Class 10
- License key mula sa nagbenta
- Internet cable para sa activation

## Hakbang
1. I-download ang getfi_v10.zip sa *Releases* (sa kanan ng page)
2. I-extract gamit ang Windows (i-right-click, Extract All)
3. I-flash ang .img sa SD card gamit ang balenaEtcher o Win32 Disk Imager
4. Ilagay ang SD card sa Orange Pi at i-boot. Maghintay ng 2 minuto
5. Mag-login sa http://10.0.0.1:8080/admin
   - Username: Admin
   - Password: Admin12345
6. Palitan agad ang password sa Change Admin Password
7. Ilagay ang license key sa *License* page at pindutin ang *Activate / Check*
